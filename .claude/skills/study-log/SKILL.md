# 스터디 로그 업데이트 스킬

## Step 1: 정보 수집

```bash
REPO_ROOT=$(git rev-parse --show-toplevel)
pwd
```

다음 파일들을 읽습니다:
- `_공통/비교분석.md`
- `_공통/다음주제.md`
- `$REPO_ROOT/스터디로그.md`

경로에서 현재 작은 주제명과 큰 주제명을 파악합니다.

## Step 2: 로그 항목 작성

수집한 내용을 바탕으로 이번 스터디 항목을 구성합니다:

```markdown
---

## [YYYY-MM-DD] [작은 주제명]

**큰 주제**: [큰 주제명]  
**참여자**: river, kon  
**마감 준수**: 예정 [마감일] / 실제 [오늘 날짜]

### 핵심 내용 요약
[비교분석의 "공동 결론" 섹션에서 2~3줄 요약]

### 다음 주제
- **주제**: [다음 작은 주제명]
- **선택 이유**: [다음주제.md의 결정 이유]
- **마감일**: [다음 마감일]
```

## Step 3: 스터디로그.md 업데이트

`$REPO_ROOT/스터디로그.md`를 편집합니다:

1. "진행 중인 큰 주제" 섹션 — 큰 주제가 바뀌었으면 업데이트
2. "스터디 기록" 섹션 — 새 항목을 **기존 항목 위에** 추가 (최신이 위로)
3. 첫 스터디라면 "(첫 스터디 후 업데이트됩니다)" 문구를 삭제하고 내용으로 교체

## Step 4: 커밋 및 push

```bash
git add "$REPO_ROOT/스터디로그.md"
git commit -m "study-log: [작은 주제명] 기록 추가 ([YYYY-MM-DD])"
git push
```

완료 후:
> "스터디 로그가 업데이트되었습니다.
>
> 오늘 스터디 요약:
> - 주제: [작은 주제명]
> - 다음 주제: [다음 작은 주제명]
> - 마감일: [날짜]
>
> 수고하셨습니다!"
