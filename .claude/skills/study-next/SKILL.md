# 다음 주제 결정 스킬

## Step 1: 현재 컨텍스트 읽기

```bash
pwd
REPO_ROOT=$(git rev-parse --show-toplevel)
```

다음 파일들을 읽습니다:
- `_공통/비교분석.md` (방금 만들어진 토론 결과)
- `$REPO_ROOT/스터디로그.md` (지금까지의 전체 흐름)

경로에서 현재 작은 주제명과 큰 주제명을 파악합니다.

## Step 2: 이번 스터디 한 줄 요약

비교분석의 "공동 결론" 섹션을 기반으로 이번 스터디를 한 줄로 요약합니다.
이 요약은 Step 5에서 다음 주제 제안의 근거로 사용됩니다.

## Step 3: 큰 주제 방향 확인 (질문 1)

AskUserQuestion:
> "현재 큰 주제 **[큰 주제명]**을 계속 진행할까요?
>
> A) 계속 진행 — 같은 큰 주제 안에서 다음 작은 주제로
> B) 새 큰 주제로 전환 — 지금까지의 학습을 마무리하고 새 방향으로"

B를 선택하면:
> "어떤 방향으로 가고 싶으신가요? 간략히 말씀해주세요."
→ 새 큰 주제 후보를 한두 개 제안한 뒤 확인

## Step 4: 다음 작은 주제 결정 (질문 2)

AskUserQuestion:
> "다음 작은 주제 아이디어가 있으신가요?
>
> A) 있다 — 직접 말씀해주세요
> B) 없다 — AI 제안 받기"

**A) 아이디어가 있는 경우:**
입력받은 아이디어를 바탕으로 1~2개의 구체화 질문:
> "좀 더 구체적으로 — [아이디어]에서 특히 어떤 부분을 다루고 싶으신가요?"

**B) 아이디어가 없는 경우:**
스터디로그.md를 분석하여 아래 기준으로 3가지 제안:
- 이번 스터디에서 나온 궁금증이나 미완 주제
- 지금까지 다룬 내용과 자연스럽게 연결되는 것
- 아직 다루지 않은 큰 주제 범위 안의 것
- 중복·너무 유사한 주제 제외

AskUserQuestion으로 선택 또는 자유 입력:
> "다음 주제 후보입니다:
> A) [제안 1]
> B) [제안 2]
> C) [제안 3]
> D) 직접 입력"

## Step 5: 마감일 설정 (질문 3)

AskUserQuestion:
> "각자 파일 작성 마감일을 정해주세요. (기본: 1주일 후 — [날짜])"
>
> A) 1주일 후 ([날짜]) — 추천
> B) 직접 입력

## Step 6: 다음 주제 파일 생성

`_공통/다음주제.md`를 생성합니다:

```markdown
# 다음 스터디 주제

큰 주제: [큰 주제명]
작은 주제: [작은 주제명]
마감일: YYYY-MM-DD
결정 이유: [이번 스터디·토론에서 나온 이유]

---

## 준비 안내

각자 `[큰 주제]/[작은 주제]/river/` 또는 `kon/` 폴더에
파일을 작성한 뒤 마감일 전까지 push해주세요.
```

## Step 7: 폴더 구조 생성

리포 루트 기준으로 다음 주제 폴더를 생성하고, git이 빈 폴더를 추적할 수 있도록 각 폴더에 `.gitkeep`을 추가합니다.

```bash
REPO_ROOT=$(git rev-parse --show-toplevel)

# 현재 존재하는 폴더 확인
ls "$REPO_ROOT/[큰 주제]/[작은 주제]" 2>/dev/null || echo "폴더 없음"

# 폴더 생성
mkdir -p "$REPO_ROOT/[큰 주제]/[작은 주제]/{river,kon,_공통}"

# 빈 폴더 추적용 .gitkeep 추가 (이미 파일이 있는 폴더는 건너뜀)
for dir in river kon _공통; do
  target="$REPO_ROOT/[큰 주제]/[작은 주제]/$dir"
  if [ -z "$(ls -A "$target")" ]; then
    touch "$target/.gitkeep"
  fi
done
```

생성 결과를 확인합니다:
```bash
find "$REPO_ROOT/[큰 주제]/[작은 주제]" -type f
```

## Step 8: 커밋 및 push

다음주제.md와 새 폴더를 함께 커밋합니다:

```bash
git add _공통/다음주제.md
git add "$REPO_ROOT/[큰 주제]/[작은 주제]/"
git commit -m "study: 다음 주제 확정 — [작은 주제명] (마감 YYYY-MM-DD)"
git push
```

완료 후:
> "다음 주제가 확정되었습니다. 마지막으로 /study-log를 실행해주세요."
