# 스터디 비교·토론 스킬

## Step 1: 현재 사용자 확인

```bash
git config user.email
```

CLAUDE.md의 참여자 표에서 위 email과 일치하는 닉네임을 찾습니다.
일치하는 항목이 없으면 멈추고 안내합니다:
> "git email이 CLAUDE.md 참여자 목록에 없습니다. CLAUDE.md를 확인해주세요."

## Step 2: 현재 주제 파악

```bash
pwd
```

경로에서 현재 폴더명(작은 주제)과 상위 폴더명(큰 주제)을 파악합니다.

## Step 3: 커밋 상태 확인

```bash
git status --short
```

커밋되지 않은 파일이 있으면 멈추고 안내합니다:
> "[닉네임]의 파일 중 커밋되지 않은 것이 있습니다. 먼저 커밋해주세요:
> `git add [파일] && git commit -m 'study: [작은 주제] [닉네임] 정리 추가'`"

## Step 4: 두 사람 파일 읽기

```bash
find river/ -name "*.md" -type f 2>/dev/null
find kon/ -name "*.md" -type f 2>/dev/null
```

발견된 모든 파일을 Read 도구로 읽습니다.
한쪽 폴더가 비어 있으면 안내합니다:
> "[닉네임]/에 파일이 없습니다. 파일 작성 후 다시 실행해주세요."

## Step 5: 비교 분석

두 사람의 전체 내용을 분석합니다.

**분석 항목:**
- 둘 다 다룬 핵심 개념과 공통된 결론
- 한쪽만 언급한 내용
- 같은 주제를 다르게 해석하거나 강조점이 다른 부분
- 서로 보완되는 관점

## Step 6: 토론 진행 (질문은 하나씩)

분석 결과를 바탕으로 AskUserQuestion으로 토론을 이끕니다.

**개인별 차이 질문** (차이점이 있는 항목마다):
> "river는 [내용A]를 이렇게 정리했고, kon은 [내용B]처럼 정리했습니다.
> river, 왜 이렇게 생각했나요? / kon, 이 부분을 다르게 본 이유가 있나요?"

**공통 심화 질문** (공통점에서 더 깊이 탐색):
> "두 사람 모두 [공통 개념]을 중요하게 봤는데, 실제로 어떻게 적용할 수 있을까요?"

STOP. 각 질문 후 반드시 답변을 받고 다음 질문으로 넘어갑니다.

## Step 7: 비교분석 문서 생성

토론이 끝나면 `_공통/비교분석.md`를 생성합니다:

```markdown
# [작은 주제] 비교분석

날짜: YYYY-MM-DD  
큰 주제: [큰 주제명]  
참여자: river, kon

---

## river 핵심 정리
[river 파일들의 핵심 요약]

## kon 핵심 정리
[kon 파일들의 핵심 요약]

---

## 공통점
[두 사람이 공통으로 다룬 내용]

## 차이점
| 항목 | river | kon |
|------|-------|-----|
| ... | ... | ... |

---

## 토론 내용
[Step 6에서 나온 질문과 답변 요약]

## 공동 결론
[토론을 통해 도출된 인사이트]
```

## Step 8: 커밋 및 push

```bash
git add _공통/비교분석.md
git commit -m "study: [작은 주제] 비교분석 추가"
git push
```

완료 후 간단히 알립니다:
> "비교분석 문서가 저장되었습니다. 이어서 /study-next를 실행하세요."
