- river가 설계한 라우터+게이트 구조를 실제 Claude Code 스킬(또는 서브에이전트)로 구현

- 컴포넌트 루프의 기계 게이트 오류 메시지에 "이렇게 고쳐라" 수정 지침을 담아 자가교정이 도는지
- 만들어보며 부딪힌 막힘을 "환경(하네스)의 결함 신호"로 읽고 무엇을 보강했는지 기록
