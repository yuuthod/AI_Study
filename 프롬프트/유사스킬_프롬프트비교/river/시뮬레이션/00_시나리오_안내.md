# 시뮬레이션 시나리오 안내

## 공통 시작 프롬프트

> 데스크탑 프로그램 사용 시간 관리 앱을 만들려고 해. 내가 codex나 chatgpt 같은 사이트에 들어있으면 생산적인 일을 하는 것이고, youtube나 instagram을 보고 있으면 비생산적인 일을 하고 있는 거야. 나중에 mac에서도 출시하려고하는데 이번에는 windows 먼저 만들고 싶어.

---

## 시뮬레이션 조건

- **목표**: 각 스킬을 통해 '설계도 md 파일' 생성까지 진행
- **사용자 답변**: 세 스킬 모두 유사한 방향의 답변 제공
- **구현 금지**: 설계도 완성 후 구현 단계 진입 없음

---

## 파일 구성

| 파일 | 스킬 | 내용 |
|------|------|------|
| `grill-me_대화록_겸_설계도.md` | `/grill-me` | 질의응답 + 설계도 (통합) |

## 공통 사용자 프로파일

시뮬레이션 전반에 걸쳐 아래와 같은 일관된 답변을 제공하는 사용자를 가정:

- **동기**: 사이드 프로젝트, 실제로 출시도 원함
- **플랫폼**: Windows 우선, 나중에 Mac
- **추적 범위**: 브라우저 URL + 앱 이름 모두
- **분류 방식**: 기본 목록 제공 + 수동 추가/제거
- **데이터**: 로컬 저장 (프라이버시 우선)
- **UI**: 시스템 트레이 + 대시보드 창
- **알림**: 한도 초과 시 실시간 알림 + 일일 요약
- **기술 스택**: Electron 계열 선호 (크로스플랫폼 고려)
