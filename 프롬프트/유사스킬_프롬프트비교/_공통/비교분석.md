## FocusTrack 프로젝트 기반 설계도 비교

동일 입력(Windows 데스크탑 생산성 앱)을 넣었을 때 각 스킬의 산출물 성격:

- **`/office-hours`** → "차트가 예뻐야 한다", "The Assignment" 포함 — 제품 감성과 다음 행동을 담은 문서
- **`/grill-me`** → 10개의 기술 결정과 각 선택 이유 — 결정 근거 추적에 최적
- **`/brainstorming`** → TypeScript 인터페이스, SQL 스키마, 파일 트리까지 — 바로 구현 가능한 스펙

세 스킬 모두 Electron + TypeScript + SQLite라는 동일한 결론에 도달했지만, **기록하는 방식과 목적이 완전히 다름**.
