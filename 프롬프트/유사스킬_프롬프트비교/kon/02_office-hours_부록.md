# 부록: YC 방식이란?

> [02_office-hours.md](02_office-hours.md)의 "YC 방식"에서 이어지는 보충 설명입니다.

YC는 **Y Combinator** — 세계에서 가장 유명한 스타트업 액셀러레이터입니다 (Airbnb, Stripe, Dropbox 배출).

YC의 "Office Hours"란 파트너(Paul Graham, Sam Altman 등)가 배치된 스타트업 창업자를 30분간 만나 아이디어를 직격으로 압박 심문하는 세션입니다. 그 핵심 철학이 `/office-hours` 스킬에 그대로 박혀 있습니다.

## YC 방식의 핵심 원칙 (스킬 내 표현 그대로)

- **구체성이 유일한 화폐**
  - "Enterprises in healthcare"는 고객이 아니다. 이름, 역할, 회사, 이유가 있어야 한다.
- **관심 ≠ 수요**
  - 대기 목록, 가입, "흥미롭다" — 아무것도 아니다. 행동이 증거다. 돈이 증거다.
- **현재 해결책(status quo)이 진짜 경쟁자**
  - 다른 스타트업이 아니라 사용자가 지금 쓰는 엑셀+슬랙 조합이 적이다.
- **좁게 먼저 (Wedge First)**
  - 지금 당장 누군가가 돈 낼 수 있는 가장 작은 버전이 뭔가?

## 실제 YC식 압박 예시 (스킬 내 포함됨)

```
┌────────────────────┬──────────────────────────────────────────┐
│     창업자 말      │                YC식 응답                 │
├────────────────────┼──────────────────────────────────────────┤
│ "모든 개발자에게   │ "지금 AI 개발 툴이 1만 개야. 특정        │
│ AI 툴을 만들고     │ 개발자가 주당 2시간 이상 낭비하는        │
│ 있어요"            │ 구체적인 작업이 뭐야? 그 사람 이름       │
│                    │ 대봐."                                   │
├────────────────────┼──────────────────────────────────────────┤
│ "모두가 아이디어를 │ "좋아하는 건 공짜야. 누가 돈 낼 의향을   │
│  좋아해요"         │ 밝혔어? 프로토타입이 망가졌을 때 화낸    │
│                    │ 사람 있어?"                              │
├────────────────────┼──────────────────────────────────────────┤
│ "전체 플랫폼을 다  │ "그건 레드 플래그야. 작은 버전으로       │
│ 만들어야 써요"     │ 가치를 못 주면, 플랫폼이 커서가 아니라   │
│                    │ 가치 제안이 불분명한 거야."              │
└────────────────────┴──────────────────────────────────────────┘
```

즉, YC 방식 = 칭찬 없이 증거만 요구하는 냉혹한 진단 — 스킬 내에도 "Anti-Sycophancy Rules"라는 이름으로 "That's interesting", "That could work" 같은 표현을 명시적으로 금지하고 있습니다.
