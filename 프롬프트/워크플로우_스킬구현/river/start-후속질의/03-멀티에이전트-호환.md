# Q3. 멀티 에이전트 호환 (AGENTS.md / CLAUDE.md / GEMINI.md)

> 질문: 어떤 AI agent든 사용자가 굳이 명령하지 않아도 같은 내용을 기본 숙지한 채 진행하도록. (AGENTS.md를 기본값으로, CLAUDE.md엔 AGENTS.md 참고하라고)

## 표준
- `AGENTS.md`(복수형) = 크로스 에이전트 공통 규약(Codex/Cursor/Zed 등 기본 인식).
- Claude Code→`CLAUDE.md`, Gemini CLI→`GEMINI.md` 우선.

## 결정 (확정 후보)
**단일 진실원천 + 얇은 포인터 (A안)**
```
AGENTS.md   ← 진실원천(라우터+불변규칙). 현 CLAUDE.md 내용이 여기로 이동
CLAUDE.md   ← 포인터: "규약은 AGENTS.md. 먼저 읽어라."
GEMINI.md   ← 포인터: 동일
```
- 효과: 어떤 에이전트든 자기 기본 파일→AGENTS.md 도달 = **무지시 동일 숙지.** 중복 0 → 한 곳만 고치면 전부 반영.

## 대안
- B. 세 파일 전체 복붙 → 수정 시 드리프트(어긋남).
- C. AGENTS.md만 → Claude/Gemini가 자기 파일 못 찾으면 미인식 위험.

## 추가
- workflow-change에 "AGENTS.md 수정 시 포인터 동기화 확인" 한 줄.
- start.md Phase 4를 이 구조로 생성하게 수정.

## 반영
- **마지막 일괄 반영에 포함:** templates/CLAUDE.md → templates/AGENTS.md 로 이동, 얇은 CLAUDE.md/GEMINI.md 포인터 생성, start.md Phase 4 수정, workflow-change 보강.
